# Notes

Native Windows app (Tauri + Rust), v0.2. Tabbed text editor with a Monospace Notes look.

```bash
npm install
npm run app
```

## Install v0.2

- Portable: [Notes-v0.2.exe](https://github.com/da0t-exe/Notes/releases/latest)
- App Installer: [Notes.appinstaller](https://github.com/da0t-exe/Notes/releases/latest) (keep the `.msix` next to it, or install from the GitHub release)

```bash
npm run dist
npm run dist:appinstaller
```
